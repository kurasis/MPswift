# Playback efficiency, second pass (2026-10-14)

The owner reports that 1.0.143-dev.1 improved CPU use and authorizes all four further optimizations. Baseline tested application source is `ba57fabd59179017dfd63eb77f0aa3b8f3817ebb`; local baseline has 366 Core passes, CLI 78 passes/15 genuine Windows-only skips, and zero build warnings/errors.

| Area | Change and compatibility |
| --- | --- |
| `PcmProcessor.Process` | Constant finite gain, disabled EQ and completed smoothing use a scalar fast path without per-frame ramp division/channel indexing. Double multiplication, saturation, nonfinite handling, protected-sample count, signed zero and partial-frame policy remain bit-identical. Ramps, active EQ, parameter smoothing and nonfinite gains retain the original path. No SIMD rounding changes or callback allocations are introduced. |
| `SettingsFile.Save` | Compare exact serialized bytes against the current file under directory/current/backup leases. Identical data returns without replacement, timestamp changes or backup rotation. Data links remain rejected even on a no-op, external replacement/removal and in-place band-array changes are detected, changed saves retain existing transactional backups and recovery. JSON schema and public save API remain. |
| `BassAudioBackend` | One process-wide BASSWASAPI notification callback, protected by reference-counted leases, increments only a revision. Owner-thread device selection caches that revision; every poll still checks the cached endpoint's ID/enabled/default policy and output-start state. Explicit Play invalidates selection. If registration fails, legacy enumeration remains. No device fallback/reconnection policy, privileges or system settings change. |
| Snapshot delivery | Only adjacent ordinary forward playing-position snapshots with identical metadata merge into one UI drain. Error/state/source/generation/format/volume/mute/seek-boundary/end/transition packets remain. Listening observes every accepted receipt under a short serialized gate before UI coalescing, using monotonic receipt time instead of delayed UI processing time. Database errors are marshalled to UI; shutdown synchronizes with the statistics chain. |

An internal coordinator receipt hook follows native-transition adoption and precedes natural-end advance. Without it, a synchronous next-load notification can reach subscribers before the previous Ended snapshot, losing short-track completion statistics. It is assembly-internal, with friends for the app/tests; existing public playback interfaces and events remain.

Authoritative callback contracts: [BASS_WASAPI_SetNotify](https://www.un4seen.com/doc/basswasapi/BASS_WASAPI_SetNotify.html) and [WASAPINOTIFYPROC](https://www.un4seen.com/doc/basswasapi/WASAPINOTIFYPROC.html), retrieved over verified HTTPS. The callback never frees output, queries devices, takes the lease gate or performs file/UI work. Native registration and unregistration occur on owner/lifecycle paths; the delegate stays rooted even if unregistration fails.

Changed-source locked local Release passes 394 Core tests, CLI 78 passes/15 Windows-only skips, zero warnings/errors. New controls cover reference PCM bits/protection, incomplete frames and fallback ramps/nonfinite gains; endpoint revision/retry/failure caching; 1,000 coalesced position packets with independent listening, fourteen critical boundaries; exact settings/no-op file identities/timestamps/backups, array edits, external replacement/removal and linked names; natural end delivered before synchronous next load. Versioning, secret-pattern controls, PowerShell parsing and whitespace checks pass.

Mandatory owned Windows `PlaybackEfficiency` measures original versus fast PCM with actual native-decoded source data, unchanged settings/no writes under actual file leases, device cache invalidation and shared native subscription lifetime, and actual WPF/SQLite receiving controlled stamped snapshots on a prepared native source. The latter intentionally uses synthetic delivery packets to test a UI backlog; it does not claim physical output playback. Existing native decode/audio/CUE/shutdown, packaged/installed EN/RU and installer gates remain. Timing values are retained rather than imposed as flaky speed thresholds. Physical default-device change/unplug, hardware-driver behavior and overall CPU savings on the owner's PC remain manual acceptance.
