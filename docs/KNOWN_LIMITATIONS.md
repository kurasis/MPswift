# Known limitations

- Stage C implements persistent tabs/entries/manual order, app settings/session restore and real cached waveform. Complete MVP acceptance still needs Windows 11 clean-machine/offline and real-device evidence; this is not a version 1.0 release.
- This Linux host cross-builds WPF and runs actual SQLite/settings/cache/core tests. Windows CI executes native decoding and real WPF integration. Actual endpoint output, listening, accurate audible position, digital capture, DPI/accessibility and offline traffic acceptance remain separate gates.
- Default shared WASAPI is the only output mode. Seek/track changes reset its graph; there is no gapless, exclusive selection, hotplug recovery, EQ, ReplayGain or crossfade yet. App gain/mute affects post-mix float PCM and never changes system volume.
- Fourteen short legal codec fixtures cover core encodings, not every P0 profile/channel layout. HE-AAC and corrupt/large real-world profile acceptance remain open. P1 decoder families are future work.
- Waveform is on demand, full-source, gain-independent all-channel extrema. Finest resolution is approximately 100 buckets/s, coarsening for long files to at most 300,000 buckets. Known finite duration is required; otherwise the real seek timeline remains available. CUE segment display is Stage D. Peak drawing uses full-scale amplitude; quiet sources have smaller envelopes.
- Tabs/rows are manually ordered. Keyboard/drag reorder is blocked during search and preserves full source order. Rich sort modes, ratings, artwork and incremental library indexing remain Stage E; queue/repeat/shuffle/history persistence and CUE remain Stage D.
- Imports stay bounded to 10,000 entries total and 100 tabs, with bounded worker/batches/traversal. Cancellation preserves confirmed imported entries. No automatic whole-library waveform scan occurs.
- Session restore retains selected and playback-source tabs separately, stable active entry and last position, volume/mute. It always prepares without autoplay. A removed active entry can be restored as a detached snapshot. Exact shuffle/queue/history restore is not claimed before Stage D.
- Settings UI is minimal: current controls cover app gain/mute and window size; waveform cache budget can be configured in versioned JSON. Full settings/localization/DPI/tray/media/single-instance IPC follow later. A data-directory ownership lock currently rejects a second writer instead of forwarding commands.
- SQLite schema 1 is the first persistent schema. Corrupt/unrecognized/newer databases are never reset to defaults. Recovery requires an explicitly selected valid backup and retains original main/WAL/SHM files. The database/settings backup uses separate files; cache is disposable and excluded. Settings parse/version errors preserve originals and stop startup, rather than silently discarding preferences.
- Portable mode needs an explicit `portable.marker` and a writable `Data` directory. Unwritable storage offers per-user fallback or exit. Media paths are currently absolute; moved external/media-root relinking is Stage E. Window width/height are saved; full window-position/maximized-state preferences follow in Stage F.
- Source content is read-only. URL/UNC/device/ADS paths, mapped network drives and known offline/recall attributes are rejected; parent/file reparse targets are checked and recursion skips junctions. Provider behavior and filesystem changes still require acceptance; path validation cannot eliminate every external race.
- Native decoder failures affect that format while retaining base decoders. Core dependency failures show details while browsing/import remains available. Cancellation quiesces waveform work and reference-counted native leases keep playback resources alive.
- Development publish is local output, not a cleared public package. BASS licensing, AAC GPL/FAAD2/commercial path, TagLib LGPL obligations, runtime notices and application source license remain release decisions.
