# Known limitations

- Stage F Windows integration passed at `39a8a25`. Stage G passes 95 tests on Linux/Windows and actual hosted Windows native stress, EN/RU WPF and extracted self-contained apphost checks at `1f3e664`; full file audits and negative integrity checks pass. The final software-routed WPF dropdown-Escape regression also passed. This is not version 1.0.
- Persistent mixer, scheduled boundaries and crossfade are implemented. Only the committed real-PCM Windows harness can establish the tested mixer combinations; endpoint capture, acoustic listening, output latency, hotplug/sleep/exclusive and lossy gapless are not claimed as verified.
- EQ uses float biquads through the production render path, conservative positive-band headroom, 20 ms parameter blending and final saturation after app volume. It is not a bit-perfect mode. ReplayGain reads tags only; unknown/invalid tags do not trigger library loudness analysis.
- Queue/history/remaining shuffle IDs restore without autoplay. Recent navigation is capped at 100 entries, explicit queue at 10,000 items and saved session JSON at 16 MiB. All-disabled/missing traversal is bounded. CUE waveform clipping reuses coarse source buckets, so boundary peaks retain bucket resolution.
- Library search is paged. Scans use bounded workers/transactions and preserve confirmed batches on cancellation; an incomplete/error traversal does not mark all unseen files missing. Watchers are hints followed by scans, not a promise that no event can ever be lost. Large Windows UI/performance and native watcher-overflow acceptance remain open.
- Index capacity is 200,000 files, 100 local roots. Playlist capacity is 10,000 total entries and 100 tabs. Sorting rewrites stable full manual order; filtering blocks manual reorder. Metadata edits, physical deletion/rename/move and tag rewriting remain excluded.
- Ratings/statistics are independent of disposable cache and playlist snapshots. Counted listening uses elapsed playing time, with conservative gaps when the UI does not receive updates; it is not an acoustic measurement. Ordinary M3U8 preserves paths/order/duplicates, not ratings/enabled/CUE semantics; CUE segment export is explicitly refused.
- Artwork has 20 MiB encoded / 40 MPixel acceptance limits, a single worker and bounded frozen-thumbnail cache. TagLib may read embedded tag data before artwork acceptance; malformed-tag process isolation and large/corrupt-artwork Windows fixtures remain future acceptance work. There is no remote artwork.
- Relink validates the replacement with an independent real decoder, retains logical/entry IDs and updates queued/history paths deliberately. Music remains in its original location. Moved portable roots need explicit relink/root selection; automatic media-root rewriting is not implemented.
- WavPack/TTA/M4B decode/seek/end/disposal fixtures passed on Windows. APE/MPC/DSF/DFF/WMA/hybrid/correction-file/full-profile fixtures remain acceptance blockers. WMA's Windows Media Format dependency is explicit; optional-component-free Windows N support is not assumed. HE-AAC remains untested.
- SQLite schema 1→2 migration creates a valid backup first; unknown/newer/incomplete schemas are rejected. Recovery is explicitly selected, validates schema/integrity/references and retains originals. Database/settings backup is separate from disposable cache. Forced crash/kill, disk-full/read-only portable workflows remain Windows acceptance tasks.
- Width/height, app gain/mute, audio processing/output requests and session are saved. Stage F adds position/maximized state, language/tray preferences, per-user IPC, SMTC, original chrome and seek Automation. Actual media keys/Narrator/physical DPI/monitor moves remain acceptance tasks.
- Source paths remain local/offline/read-only with lexical, drive, attribute and reparse validation. External provider/filesystem races cannot be eliminated by a path check. Full source-byte/handle workflows are included in the expanded Windows harness passed on the recorded Stage D/E Windows source.
- Native dependencies and upstream notices are development output. Public redistribution, BASS commercial terms, AAC GPL/FAAD2 path, TTA LGPL obligations, TagLib obligations and app licensing remain separate release decisions. No public release was published.

- Portable development ZIP generation is available locally, with full hashes, runtime/native files, local help and available upstream notices/declarations. Distribution approval is false: intended use/app source license, AAC GPL/licensed alternative, TagLib/TTA matching-source/relinking and Windows SDK redistributable/notices review remain open. Metadata alone does not satisfy those obligations. No native binary/package was uploaded as a CI artifact or release.
- Local diagnostics are bounded and redact configured personal prefixes, not a guarantee that every arbitrary exception contains no private information. They are never uploaded. Logs can be dropped when their 128-entry queue is full; disk-write failure remains queryable. Inspect before sharing.
- The resource manager now binds to the persisted app language rather than an IPC/background ambient culture. Existing user-provided tab names/metadata retain their original language. High-contrast brushes apply app-wide; manual screen-reader/DPI/high-contrast and actual media-key acceptance remains open.
