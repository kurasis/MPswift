# Known limitations

Current baseline: `f689fdc038c8`, development build `0.2.72-dev.1`; 249 tests per OS, 216 bounded parser cases, EN/RU/extracted WPF and 577-file/13-native package verification passed. [Exact evidence](evidence/security-deepening-windows.json). Diagnostic privacy changes receive their own CI. This is not accepted stable version 1.0; [remaining work](REMAINING_WORK.md) and [release gates](RELEASE_ACCEPTANCE.md) define current blockers. Older source snapshots below are historical; the corrections in this paragraph supersede their pending notes:

- G8 passed 30 committed profiles, WMA lossless/Pro and >4 GiB RF64; long M4B/APE checks also pass. HE-AAC/APE/MPC/WV hybrid are not blanket untested blockers. Actual Windows N, encoded >4 GiB APE and other uncovered representative combinations remain open.
- G9 actual NTFS full-disk rollback, read-only portable fallback, production migration kill/retry, watcher overflow and cancellation passed. Actual power-loss/manual Windows 11 acceptance remains open.
- Malformed tags/artwork and 216 deterministic bounded parser cases passed in disposable Windows workers. Production parser process isolation, exhaustive fuzzing and individual mutable-file/streaming/WVC races remain open. Test Job containment is not a production sandbox.
- The paused EQ processor-retention issue is corrected without changing its 20 ms curve. Queue/session JSON is limited to 16 Mi UTF-16 units rather than a byte-size promise.
- Latest directory leases protect storage/backup chains; same-user pre-start compromise, hardlinks/individual files/WAL and stage cleanup intervals remain investigation boundaries. Arbitrary closed-addon internal loads are not fully established.
- Configured diagnostic paths now cover plain/default-JSON/slash representations and log Operation; arbitrary secrets/unconfigured paths can remain. The current prefix correction requires its own CI.
- Publisher signing remains absent; hashes are integrity checks relative to trusted metadata. Licensing, actual clean Windows 11, devices/Narrator/physical DPI and two-hour real output remain release gates.

Cache reads/LRU touches now use the same validated handle, and linked Windows cache entries regenerate without touching outside targets. New SQLite backup/recovery outputs are reserved atomically; failed creation no longer authorizes deleting a pre-existing temporary entry. These narrow corrections require their own Windows CI and preserve the remaining main-data-file/streaming/stage-cleanup boundaries. [Exact scope](FILE_CONTINUITY_2026-10-07.md).

## Historical checkpoints

- Stage F Windows integration passed at `39a8a25`. Stage G4–G7 passes 115 tests on Linux/Windows, 21 native profiles, complete ZIP restore, storage/artwork and measured search/scroll plus extracted apphost checks at `a00ee6c`; full file audits and negative integrity checks pass. The final software-routed WPF dropdown-Escape regression also passed. This is not version 1.0.
- Persistent mixer, scheduled boundaries and crossfade are implemented. Only the committed real-PCM Windows harness can establish the tested mixer combinations; endpoint capture, acoustic listening, output latency, hotplug/sleep/exclusive and lossy gapless are not claimed as verified.
- EQ uses float biquads through the production render path, conservative positive-band headroom, 20 ms parameter blending and final saturation after app volume. It is not a bit-perfect mode. ReplayGain reads tags only; unknown/invalid tags do not trigger library loudness analysis.
- Queue/history/remaining shuffle IDs restore without autoplay. Recent navigation is capped at 100 entries, explicit queue at 10,000 items and saved session JSON at 16 MiB. All-disabled/missing traversal is bounded. CUE waveform clipping reuses coarse source buckets, so boundary peaks retain bucket resolution.
- Library search is paged. Scans use bounded workers/transactions and preserve confirmed batches on cancellation; an incomplete/error traversal does not mark all unseen files missing. Watchers are hints followed by scans, not a promise that no event can ever be lost. Hosted warm search/scroll measurements pass; reference Windows 11/cold/steady performance and native watcher-overflow acceptance remain open.
- Index capacity is 200,000 files, 100 local roots. Playlist capacity is 10,000 total entries and 100 tabs. Sorting rewrites stable full manual order; filtering blocks manual reorder. Metadata edits, physical deletion/rename/move and tag rewriting remain excluded.
- Ratings/statistics are independent of disposable cache and playlist snapshots. Counted listening uses elapsed playing time, with conservative gaps when the UI does not receive updates; it is not an acoustic measurement. Ordinary M3U8 preserves paths/order/duplicates, not ratings/enabled/CUE semantics; CUE segment export is explicitly refused.
- Artwork has 20 MiB encoded / 40 MPixel acceptance limits, a single worker and bounded frozen-thumbnail cache. TagLib may read embedded tag data before artwork acceptance; actual corrupt/oversized/truncated portrait artwork Windows checks pass; malformed/huge-tag process isolation remains future acceptance work. There is no remote artwork.
- Relink validates the replacement with an independent real decoder, retains logical/entry IDs and updates queued/history paths deliberately. Music remains in its original location. Moved portable roots need explicit relink/root selection; automatic media-root rewriting is not implemented.
- WavPack/TTA/M4B decode/seek/end/disposal fixtures passed on Windows. RF64 PCM16/WMA v2/DSF/DFF conversion fixtures now pass; APE/MPC/HE-AAC/WMA lossless/N/WV hybrid/correction/full profiles remain blockers. WMA's Windows Media Format dependency is explicit; optional-component-free Windows N support is not assumed. HE-AAC remains untested.
- SQLite schema 1→2 migration creates a valid backup first; unknown/newer/incomplete schemas are rejected. Recovery is explicitly selected, validates schema/integrity/references and retains originals. Database/settings backup is separate from disposable cache. The owned apphost kill/rollback/restart workflow passes; kill during migration, power-loss, disk-full/read-only portable workflows remain acceptance tasks.
- Width/height, app gain/mute, audio processing/output requests and session are saved. Stage F adds position/maximized state, language/tray preferences, per-user IPC, SMTC, original chrome and seek Automation. Actual media keys/Narrator/physical DPI/monitor moves remain acceptance tasks.
- Source paths remain local/offline/read-only with lexical, drive, attribute and reparse validation. External provider/filesystem races cannot be eliminated by a path check. Full source-byte/handle workflows are included in the expanded Windows harness passed on the recorded Stage D/E Windows source.
- Native dependencies and upstream notices are development output. Public redistribution, BASS commercial terms, AAC GPL/FAAD2 path, TTA LGPL obligations, TagLib obligations and app licensing remain separate release decisions. The owner authorizes automated development prereleases after successful main CI; stable release acceptance remains open.

Distribution approval is false: intended use/app source license, AAC GPL/licensed alternative, TagLib/TTA matching-source/relinking and Windows SDK redistributable/notices review remain open.
