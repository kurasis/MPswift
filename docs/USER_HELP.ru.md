# MPswift — локальная справка

Это сборка для разработки под Windows x64. Целевая система выпуска — Windows 11; проверки чистой системы, работы без сети и реального аудиоустройства ещё не завершены. Самодостаточному приложению не нужны сетевые сервисы, учётная запись, отдельно установленный .NET или SDK. Распакуйте всю папку и запустите MPswift.exe. Не переносите один исполняемый файл. Перед распространением см. DEVELOPMENT-ONLY.txt и список обязательств по зависимостям.

## Файлы и плейлисты

Перетащите папку на панель вкладок плейлистов, чтобы создать новый плейлист с именем папки и музыкой из её подпапок. Несколько папок создадут отдельные вкладки. Отдельные файлы при смешанном перетаскивании добавляются в исходный выбранный плейлист. Если перетащить папку на список треков, музыка добавится в выбранный плейлист.

Добавляйте локальные файлы или папки кнопками внизу, сочетаниями Ctrl+O / Ctrl+Shift+O или перетаскиванием. Сам импорт не включает звук. Меню действий открывает вкладки, сортировку, копирование пути, Проводник, свойства, медиатеку, импорт/экспорт и резервное копирование. Поиск фильтрует видимые записи, сохраняя последовательность воспроизведения. Перед изменением порядка очистите поиск. Enter воспроизводит выбранный трек; Delete убирает записи, сохраняя аудиофайлы. Ctrl+A выбирает видимые записи. Ctrl+N создаёт вкладку; F2 переименовывает при фокусе на вкладках. Ctrl+Shift+Up/Down или перетаскивание меняет ручной порядок.

В медиатеке выбираются локальные папки, запускается отменяемое сканирование и постраничный поиск без шаблонов. Оценки и история хранятся в базе данных. Обложки берутся из локальных тегов или соседних изображений cover/folder. Сетевые пути, удалённые диски и облачные файлы, требующие загрузки, не принимаются. После отмены импорта или сканирования записанные результаты сохраняются; частичные ошибки показаны в технических сведениях.

Экспорт M3U8 сохраняет обычные локальные пути, порядок и повторы. PLS/M3U8/CUE не импортируют документы рекурсивно. Для старых кодировок есть отдельный диалог. Логические сегменты CUE нельзя полноценно экспортировать в обычный M3U8 — такой экспорт отклоняется. Замена пути проверяет новый файл независимым декодером и сохраняет идентификаторы; музыка не перемещается и не перезаписывается.

## Воспроизведение и звук

Пробел включает воспроизведение/паузу вне элементов, использующих пробел. Alt+Left/Right выбирает предыдущий/следующий трек. Ctrl+Left/Right перематывает на пять секунд вне текстовых полей; волна с фокусом также принимает стрелки/Home/End без модификаторов. Ctrl+Up/Down меняет громкость приложения на пять процентов. Ползунок и волна предоставляют диапазон для клавиатуры и Automation. Громкость и отключение звука не меняют системную громкость Windows или сохранённую волну.

Снимки записей в очереди играют перед плейлистом и сохраняются при изменении источника. «Воспроизвести следующим» сохраняет порядок выбранной группы. Очистка очереди не прерывает текущий трек. «Предыдущий» использует историю реально начатых треков и после трёх секунд начинает текущий заново. Ручной переход к следующему выходит из повтора одного трека. Случайный порядок использует набор оставшихся записей; поиск не меняет источник.

В настройках аудио выбираются устройство по умолчанию Windows или конкретный выход, общий либо монопольный режим. Изменение выхода приостанавливает звук. Если монопольный режим недоступен, появляется ошибка; общий режим автоматически не включается. После изменения устройства выберите выход и явно нажмите «Воспроизвести». Проверки горячего подключения и сна на реальном оборудовании ещё открыты.

Эквалайзер, предусиление, ReplayGain из тегов и кроссфейд используют обработку float. Без тегов ReplayGain применяется 0 дБ. Усиление компенсируется запасом, а выход за диапазон ограничивается. Кроссфейд по умолчанию выключен, сокращается для коротких треков и обходится для непрерывного CUE и повтора одного трека. Режим bit-perfect не заявляется. Профили форматов, непрерывность на реальном выходе и специализированные кодеки требуют собственных результатов; см. FORMAT_SUPPORT.md.

## Windows и данные

Второй запуск активирует текущий экземпляр пользователя. Локальные пути добавляются без звука; --play явно запускает первый новый трек. -- завершает разбор опций. Неизвестные параметры и произвольные IPC-команды отклоняются. Медиакоманды используют Windows SMTC; доступность API и проверка физических клавиш учитываются отдельно.

Трей позволяет показать/скрыть окно, включить воспроизведение/паузу, перейти вперёд/назад и выйти. Скрытие не останавливает звук. Закрытие по умолчанию завершает работу; закрытие в трей включается отдельно в настройках поведения. Английский или русский язык применяется после перезапуска. Высокий контраст следует Windows. F1 открывает локальную справку без браузера.

Файл portable.marker выбирает папку Data рядом с приложением. Удалите маркер до запуска, чтобы использовать %LOCALAPPDATA%/MPswift/LocalAudioPlayer/. Если переносимая папка недоступна для записи, требуется явный выбор хранилища пользователя. При переносе сохраняйте всю папку Data. Музыка в неё не копируется; изменившиеся абсолютные пути требуют замены. Закрытие сохраняет сеанс; восстановление не включает звук.

Резервное копирование базы и настроек отделено от временного кэша Cache/Waveforms. Не удаляйте базу для очистки кэша. Повреждённые или более новые данные сохраняются и отклоняются; восстановление требует выбранной корректной резервной копии. Локальные журналы ограничены пятью файлами по 2 МиБ; личные префиксы путей скрываются. Проверьте текст перед передачей. Приложение не загружает журналы в сеть. Ошибка диска остаётся видимой, даже если журнал тоже не может записать её.

Контрольные суммы находятся в SHA256SUMS.txt; scripts/Verify-Candidate.ps1 в репозитории проверяет весь состав. Метаданные лицензий и уведомления включены в notices/, native/ и docs/. Это не заменяет обязательства по соответствующим исходникам или коммерческому использованию. Сборка не подписана; публичный выпуск не создавался. Точный список оставшихся проверок — в RELEASE_ACCEPTANCE.md.

Если настройки повреждены или отсутствуют, но предыдущая копия исправна, при запуске появится предложение восстановить её. При выборе «Нет» приложение завершится без изменения данных. При восстановлении повреждённый файл сохраняется отдельно как `settings.json.preserved-*`. Настройки неподдерживаемой версии не заменяются старой копией: используйте совместимую версию приложения. Восстановление базы данных — отдельная операция.


Действие «Резервная копия» сохраняет полный локальный ZIP: плейлисты, очередь, медиатеку, оценки, историю и настройки. Музыка, кэш и журналы в него не входят. «Восстановить резервную копию» проверяет архив до замены сохранённых файлов, оставляет текущую базу и настройки отдельно и восстанавливает без автозапуска музыки. При неверном архиве текущие данные сохраняются. Выбирайте новое имя копии: существующие файлы не перезаписываются. Прежние копии .db восстанавливают только базу. После копии с другим языком перезапустите приложение.

## Настройки и разделители альбомов

Шестерёнка в заголовке окна открывает настройки. Можно выбрать русский или английский язык (применяется после перезапуска MPswift), включить заголовки альбомов и папок, выбрать сворачивание в трей при закрытии. «Применить» сохраняет выбор, «Отмена» оставляет прежние значения. Раздел «Звук» открывает настройки устройства вывода, эквалайзера, ReplayGain и плавного перехода.

При переносе папки на вкладки создаётся плейлист с содержимым вложенных папок. Заголовки берут название альбома из тегов, а при их отсутствии — имя папки. Подписи папок различают диски и подпапки, счётчики показывают видимые треки. Поиск и перемещение треков обновляют разделители, сохраняя порядок воспроизведения. Меню «⋯» разбито на действия с плейлистом, выбранными треками, очередью и файлами.

## Цельный FLAC-альбом и CUE

Если в одном FLAC записан весь альбом, оставьте рядом файл .cue. При добавлении папки или FLAC единственная корректная CUE-разметка, ссылающаяся на этот FLAC, автоматически создаст строки отдельных песен. Аудиофайл не разрезается и не изменяется. Папка с FLAC и его CUE не добавляет цельный альбом повторно.

Для уже добавленного FLAC выделите строку (можно несколько альбомов), затем **⋯ → Выбранные треки → Развернуть FLAC в песни по CUE**. Имя FILE внутри CUE должно совпадать с реальным FLAC. При отсутствующей, неоднозначной, повреждённой или выходящей за длительность файла разметке исходная строка сохраняется. Для старой кодировки выберите «Файлы и резервные копии → Импорт документа с выбором кодировки», откройте .cue и укажите его кодировку. CUE с несколькими исходными файлами можно импортировать отдельно. Без временной разметки файл остаётся цельным: границы по тишине не угадываются.
